# 前端组件使用规范：BizUnit 优先于 antd

业务项目（含部署到应用中心的应用）写列表、表单、弹窗、详情时，**优先使用 BizUnit 体系的远程组件**，尽量不使用 antd 的同类组件。组件统一用 `createWithRemoteLoader({ modules: [...] })` 引入。

具体 props 以组件文档为准（开发者文档 MCP `search_document_index`，如 query `components-core:InfoPage`），没有文档支撑的 API 不要写。

## 选型顺序

1. **完整 CRUD 模块**：用 `components-admin:BizUnit` 作为容器（列表 + 筛选 + 新建/编辑弹窗 + 操作列），结构见 [创建业务模块.md](./创建业务模块.md)
2. **单独的列表 / 表单 / 弹窗 / 详情**：用下表中的 `components-core` 组件
3. 以上都满足不了时才退回 antd，并在代码旁用一行注释说明原因

## 组件对照

| 场景 | 使用（token） | 不使用 |
|---|---|---|
| 分页列表 | `components-core:TablePage`（默认导出 `TablePage`） | antd `Table` + 手写分页 |
| 静态表格 | `components-core:TablePage@Table` | antd `Table` |
| 详情里的小表格 | `components-core:InfoPage` 的 `TableView` | antd `Table` |
| 列表筛选 / 搜索 / 顶部按钮 | `TablePage` 的 `filter`、`search`、`buttonGroup`；单独的筛选栏用 `components-core:Filter` | antd `Form` 自拼筛选栏 |
| 表单 | `components-core:FormInfo`（字段 + `rule` 校验）；整页表单用 `components-core:FormInfo@Form` | antd `Form` / `Form.Item` |
| 表单弹窗 | `components-core:FormInfo@useFormModal` | antd `Modal` 包 antd `Form` |
| 普通弹窗 | `components-core:Modal@useModal` | antd `Modal` / `Modal.info` |
| 确认 | `components-core:Modal@useConfirmModal`；操作按钮用 `components-core:ButtonGroup` 的 `confirm` | antd `Modal.confirm` / `Popconfirm` |
| 详情 | `components-core:InfoPage`（`InfoPage.Part` + `Content`），页面外壳 `components-core:Layout@Page` | antd `Descriptions` / `Card` 堆字段 |

antd 仍然可以用于布局与基础控件：`Flex`、`Space`、`Button`、`Typography`、`Tag`、`App`（`message` / `notification`）、`Spin`、`Empty` 等。

## 已废弃：components-core:Table

`components-core:Table`（含 `components-core:Table@TablePage`）已废弃，**新代码不要使用**，分别改用 `components-core:TablePage` 与 `components-core:TablePage@Table`。两者列配置不同，迁移时要一起改：

| 旧 `components-core:Table` | 新 `components-core:TablePage` |
|---|---|
| 列类型写在 `type`（如 `mainInfo`、`serialNumber`、`datetime`） | 列类型写在 `renderType`：`main` / `amount` / `tag` / `status` / `tagList` / `list` / `options` / `description` / `enum`，可加 `short` / `small` / `large` 修饰（如 `tag-short`）；日期、金额用 `format`（如 `format: 'date'`） |
| `valueOf: item => ...` | `getValueOf: item => ...` |

旧代码在本次改动涉及时再迁移，不要为此单独大面积改。

## 示例

### 分页列表

```javascript
import { createWithRemoteLoader } from '@kne/remote-loader';

const List = createWithRemoteLoader({
  modules: ['components-core:TablePage', 'components-core:Global@usePreset']
})(({ remoteModules }) => {
  const [TablePage, usePreset] = remoteModules;
  const { apis } = usePreset();
  return (
    <TablePage
      {...apis.sample.list}
      name="sample-list"
      search={{ name: 'keyword', label: '关键词' }}
      columns={[
        { name: 'name', title: '名称', renderType: 'main' },
        { name: 'status', title: '状态', renderType: 'status', getValueOf: item => ({ type: item.status === 'open' ? 'success' : 'default', text: item.status }) },
        { name: 'createdAt', title: '创建时间', format: 'date' },
        { name: 'options', title: '操作', renderType: 'options', fixed: 'right', getValueOf: item => [{ children: '编辑', onClick: () => {} }] }
      ]}
    />
  );
});
```

### 表单弹窗

```javascript
const Create = createWithRemoteLoader({
  modules: ['components-core:FormInfo', 'components-core:FormInfo@useFormModal', 'components-core:Global@usePreset']
})(({ remoteModules, onSuccess }) => {
  const [FormInfo, useFormModal, usePreset] = remoteModules;
  const { Input, TextArea } = FormInfo.fields;
  const formModal = useFormModal();
  const { ajax, apis } = usePreset();
  return (
    <Button
      onClick={() => {
        const api = formModal({
          title: '新建',
          formProps: {
            onSubmit: async data => {
              const { data: resData } = await ajax(Object.assign({}, apis.sample.create, { data }));
              if (resData.code !== 0) return false;
              api.close();
              onSuccess?.();
            }
          },
          children: <FormInfo list={[<Input name="name" label="名称" rule="REQ LEN-0-50" />, <TextArea name="description" label="描述" />]} />
        });
      }}
    >
      新建
    </Button>
  );
});
```

### 普通弹窗与确认

```javascript
const [useModal, useConfirmModal] = remoteModules; // 'components-core:Modal@useModal', 'components-core:Modal@useConfirmModal'
const modal = useModal();

modal({
  title: '快览',
  children: ({ close }) => <InfoPage>...</InfoPage>,
  onConfirm: () => {}
});
```

### 详情

```javascript
const Detail = createWithRemoteLoader({
  modules: ['components-core:InfoPage', 'components-core:Layout@Page']
})(({ remoteModules, data }) => {
  const [InfoPage, Page] = remoteModules;
  const { Content } = InfoPage;
  return (
    <Page title={data.name}>
      <InfoPage>
        <InfoPage.Part title="基本信息">
          <Content list={[{ label: '名称', content: data.name }, { label: '状态', content: data.status }]} />
        </InfoPage.Part>
      </InfoPage>
    </Page>
  );
});
```

## 规则

1. 新代码直接按上表写；改旧代码时只替换本次改动涉及的部分，不顺手大面积重构
2. 弹窗里展示详情用 `InfoPage`，不要在 `useModal` 里再塞 antd `Descriptions`
3. 表单校验写在字段的 `rule` 上（如 `REQ LEN-0-50`、`EMAIL`），不另写 antd `rules`
4. 退回 antd 时必须注释原因，例如「需要拖拽排序表格，TablePage 不支持」

## 禁止

- 列表、表单、弹窗、详情用 antd `Table` / `Form` / `Modal` / `Descriptions` 自拼（已注释原因的例外除外）
- 新代码引入已废弃的 `components-core:Table` 或 `components-core:Table@TablePage`
- 同一页面里 BizUnit 组件与 antd 同类组件混用（如 `TablePage` 旁边再放一个 antd `Table`）
- 不查文档凭记忆写组件 props 或 token
